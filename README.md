# 记忆库套件（memory-kit）

> **给你的 AI 助手装一套记忆** —— **随盘走、可移植、零密钥**。
> **版本**：**0.1.32**（**「能随时带走」版** · 见同目录 `VERSION`）｜ **骨架规范**：`memory-root/2`
> **已公开发布版＝0.1.23**（GitHub）；本版为其后**本机实测续作**（部署进库 ＋ 母体适配层 ＋ **带走自检**）｜ **CHANGELOG 逐节可查**

**若你是被派来安装的 Agent ⇒ 直接读 [`BOOTSTRAP.md`](BOOTSTRAP.md)**（人读本件即可）。

---

## 一句话

**一次适配，换终身成长** —— 装上做一次宿主适配，之后只剩下「**记忆的成长**」。

**它不是**：不是聊天机器人、不是云服务、不是某个平台的插件（**插件只是"接入壳"，不是本体**）。

## Prerequisites（前置条件）

| # | 需要 | 说明 |
|---|---|---|
| 1 | **你已在用某个 AI Agent 产品** | 任一类皆可；本套件对宿主**零假设** |
| 2 | 会跑**一条命令** | 用来初始化你的记忆库 |
| 3 | 一个**你自己掌控的目录** | 记忆是**你的文件**，放在你能看见的地方 |

> **使用人群：不限定、不预设。** —— 不挑谁用，也不假设拿来做什么。

## Quickstart

```bash
# 1) 取件：clone ／ 解压 ／ 直接复制目录 —— 三者等价
# 2) 初始化（在你想放记忆的目录跑）
python install/init_instance.py --target <你的库目录>
# 3) 自检：确认"新生儿态"合法（不崩／不装懂／主动索要）
python install/verify.py --root <你的库目录>
# 4) 让你的宿主读库根 AGENTS.md（一次适配，见 spec/适配契约）
```

**首次跑完你会看到**：库根出现 `AGENTS.md` ＋ `01-记忆档案/` 骨架；**内容为空是正常的** —— 这是**合法的出生态**。

**换机／在别人的电脑上**：把库根的 **`接上我.md`** 拖进对话框即可 —— 它会让那个 AI 当场接入你的库（**L0 递进门 · 零配置**）。

## 对你的承诺（**三条** · 逐字全文见 [`spec/对外承诺.md`](spec/对外承诺.md)）

> **书写纪律**：每条承诺**都连"不覆盖"一起写** —— **只写上半句 ⇒ 承诺为假**（三条完整版＋对应物＋边界，见 `spec/对外承诺.md`）。

| # | 承诺 | 一句话 | 你的验证方式 |
|---|---|---|---|
| 1 | **随盘走**（可携带） | 记忆是**你自己的普通文件**；**换宿主／换机器／换盘 ＝ 复制目录** | `kernel-skeleton/` 复制即用；`tools/memory.py reindex` 证明索引可由真源重建 |
| 2 | **不训练** | **不上传、不收集、不用你的记忆训练模型** | 套件内**无 HTTP／socket／遥测**（静态普查检出 0 处）—— **结构上做不到** |
| 3 | **本库内删除可复核** | `purge` 后**本库根内**不再含该条正文及其库内副本；**可重建派生物**重建后不含该条；回执**仅存路径与哈希** | `tools/purge.py audit` ＋ `tests/deletion_audit.py`（**D8 针式探针**） |

**三条的不覆盖（同样重要）**：① 换宿主**须重焊五个焊点**（注入／写触发／检索／确认／**删除触达**）；② 记忆**会被宿主读进上下文** —— 此后是否离开本盘、是否被用于训练**取决于宿主**；③ 删除**只核「本库根」** —— **不覆盖**库外副本／宿主侧缓存与对话历史／介质级取证（**禁**写「彻底／永久／不可恢复」「防篡改」）；④ **不承诺并发安全**（同一时刻只应有一处在写）。

**不做承诺的地方**（防范围蔓延）：不承诺与同类**功能对等**；不承诺**跨库合并／跨设备自动去重**（只做**分叉侦测**）；**不主张首创、不主张业界首个**（同向者见 [`ACKNOWLEDGMENTS.md`](ACKNOWLEDGMENTS.md)）；**不面向合规审计／多租户场景提供保证**（本套件**无租户模型**，**不生成审计所需的合规留痕**）。

## 检索的边界（**如实** · 2026-10-02 实测）

`ask` 是**词法相关度检索**（倒排 ＋ BM25 ＋ **零依赖分词**），**不是语义检索** —— 能命中什么、命不中什么，一次说清：

| 情形 | 行为 | 说明 |
|---|---|---|
| **≥2 个汉字**的查询（含**非连续子串**，如查「喜欢咖啡」命中「我喜欢喝拿铁咖啡」） | ✅ 命中 | 中文按**单字**（unigram）＋ **二元组**（bigram）切 |
| **单字**查询（如「咖」） | ✅ 命中（`v0.1.14` 起） | 索引含单字键；**升级后旧索引自动判失效并重建**（判据＝索引格式版本升位） |
| **同义改写、且无共同字**（如用「喜欢咖啡吗」去查「我平时爱喝拿铁美式」） | ❌ **不命中** | **词法上限** —— 本套件**无词表、无向量**；要语义请用你自己的宿主模型 |
| **跨词界**：由**相邻两字**拼成的串（如「州工」来自「苏州」＋「工作」） | ⚠️ **会命中** | **已知局限**：bigram **不含词界信息** —— 业界同类 bigram 方案（Elasticsearch `cjk_bigram`／SQLite FTS5 `cjk`）同此 |

**代价先说清**：单字入索引令**中文索引体积约 ×1.34**（本机实测：真实中文语料 20 件 — 词项 +19.7%、体积 243,202 B → 327,027 B）。**英文/数字语料不受影响**（仍按词元切）。

### ★ 协议成本（**先说清 · 诚实声明**）

用本套件**不是零代价** —— 它换掉的是「跨会话失忆」，不是「零开销」：

| # | 成本 | 量级 |
|---|---|---|
| 1 | **每会话开头读入口件与必读件** | **5 件 · 约 10 KB 上下文**（一次性装载） |
| 2 | **写库要「找落点」** | 比「随手记」**多几秒** —— 每层有归属、每项要过入口闸 |
| 3 | **它不会自己到点提醒你** | **本套件无执行体、无守护进程** ⇒「到点叫我」是**宿主的能力**，不是库的能力。**禁在库里写「已设提醒」** —— 那是撒谎 |

> **为什么写明**：「**不打扰**」与「**零成本**」是两回事 —— 先把成本说清，才不会在装完之后才失望。
