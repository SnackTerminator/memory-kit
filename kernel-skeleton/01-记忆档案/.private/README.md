# `.private/` —— 敏感件隔离区

> **本目录是约定，不是机制。** 放**不想让陌生宿主读到的内容**。

- **谁读得到**：**已信任的宿主**（`MANIFEST.md` 的 `carrier.trust`）可读；
  **陌生宿主（`host_id` 不在 `trust`）视为 guest ⇒ 本目录不出库**（不进读取集、不被复述）。
- **为什么需要它**：物理分离防的是"记忆被装进 Agent 应用里"，**防不了"被 Agent 读走"** ——
  一个陌生宿主读到你的内容，就把它带进了它自己的上下文。
- **放什么**：身份信息、联系方式、客户／合同要点、任何**换个人来用就不该看到**的东西。
- **不放什么**：流程与规则（那些是给别人也能看的框架件 —— 放正常位置）。

> 口径见 `MANIFEST.md` §⑦。
