# 本库内删除可复核（对外口径 · 唯一真源）

> **性质**：**对外承诺的边界明文**。本件是「删除」这一能力**对外表述的唯一真源** —— 任何对外件（README／docs／发行说明）写删除相关承诺，**须与本件逐字一致**。
> **纪律**：**机制先于文案** —— 本件随 `tools/purge.py` 同批出厂；**脚本不在包内 ⇒ 本件不得先行对外**。
> **依据**：`设计_删除可核_v1_20261001.md`（**v1.1** · 外部评审 15 项全采纳）｜承 `E76`（**回执 ≠ 事实**）。

---

## 一、承诺（对外可用的口径 · 逐字）

> **本库内删除可复核**：`purge` 后，**本库根内**不再含该条正文及其库内副本；**可重建派生物**重建后不含该条；回执**仅存路径与哈希**，可机械复核。

## 二、不覆盖（**必须同时写出，禁只写上半句**）

> **不覆盖**：
> ① **库根之外**的任何副本（另存目录／他机／**同步盘及其历史版本**／备份 —— 只出**传播说明**）；
> ② **宿主应用自身**的缓存、日志与**对话历史**；
> ③ **存储介质的取证级恢复**（本命令为**文件系统级逻辑删除**，**不做扇区擦除**）。

**为什么写这三条**：它们是**最容易被一击即破的四个方向**（回收站／`.bak`／历史版本｜备份与同步盘历史｜宿主侧缓存与对话历史｜介质级取证）。**不写＝承诺为假**。

## 三、四要素（强制句 · 每次核验输出必带）

**本库根** ／ **逻辑删除** ／ **不含库外与宿主侧** ／ **自存证 ≠ 第三方公证**。

## 四、语言禁令

- **禁**裸用「**彻底**／**永久**／**不可恢复**」。
- 对外写「**本库内删除可复核**」；**不写**「删除可核」四字裸称。
- **禁**写「**防篡改**」——回执链只能「**可发现意外与局部改写**」（无签名、无外锚）。

## 五、恢复重放（**备份场景的必读条**）

> **用备份恢复本库后，须重放回执或重跑 `audit`**，否则删除可能**随恢复回退**。
> 回执**不含正文**，**可随备份一起保存**。

**依据**：Cassandra `gc_grace_seconds` 教训 —— **删除标记必须活过「最后一个可能带回旧数据的通道」**（备份／他机／离线副本）；**恢复/合并必须先应用删除**（tombstone-first）。

## 六、命令（包内）

```bash
python tools/purge.py purge  --root <库根> --target <相对路径> --operator <不透明 id> --preview
python tools/purge.py purge  --root <库根> --target <相对路径> --operator <id> \
       --yes --receipt-fingerprint <preview 输出的期望值；首次传 NEW>
python tools/purge.py audit  --root <库根> [--target <相对路径>]
python tools/purge.py verify --root <库根>
python tests/deletion_audit.py --root <库根> [--target <相对路径>]   # 验收薄壳（CI/交付可用）
```

**覆盖规则（按内容同一性，不按同名）**：`primary`（目标本体）｜`archive-copy`（`_archive/**`）｜`hist-snapshot`（`_meta/curation/hist/**` 全文前像）｜`other-copy`（全根其余，含 `.bak_*`）。
**同路径但内容不同**（旧版本）⇒ **默认只列不删**；`--sweep-archive` 才一并清。

**退出码**：`0` 成功／预览完成 ｜ `1` 有残留或拒 ｜ `3` 参数/IO 错。

## 七、边界之外（**明确不承诺的**）

| # | 不承诺 | 理由 |
|---|---|---|
| 1 | 语义级「不留痕」（改述／摘要里仍可能提到） | 判据**以针为界**（精确子串），**不承诺语义级** |
| 2 | 库外副本的清除 | 不可控 ⇒ 只出**传播说明** |
| 3 | 抗有磁盘写权限对手的整链重写 | 无签名无外锚 ⇒ 只做到「可发现」 |
| 4 | 「已清」的检测面（无重建命令的人手镜像等） | 降级为**检测面**：**出残留清单由人清**，**不许写成"已清"** |
