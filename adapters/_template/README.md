# adapters/_template —— 适配页骨架（**空壳**）

> **本目录是出厂自带的空壳** —— 它**不属于任何宿主**，是你长出自己适配页的起点。
> **为什么出厂不带你的适配页**：适配层允许写宿主真名/路径（豁免区），但**豁免区的内容不随包分发**（见 `发行物清单.md`）。

## 怎么用

1. **复制到 `adapters/<你的宿主代号>/`**（代号用 `h_<uuid>` 或产品小写名，**不写真名**）
2. **填三件**（缺件会被自检报 WARN，不 FAIL —— 允许渐进）：

| 件 | 写什么 | 必填 |
|---|---|---|
| `manifest.json` | 接入声明：形态（裸库直读／接线注入）＋ 接线方式 ＋ 授权 | ✅ |
| `NOTES.md` | **该宿主的坑与验收状态**（≤45 行）｜**真名/路径只写这里** | ✅ |
| `ENVIRONMENT.md` | 本机落点：库根指向哪、配置文件在哪、怎么验证 | ⭕（接线注入才需） |

## 三种形态（承 `adapters/CONTRACT.md`）

| 形态 | 何时用 | 成本 |
|---|---|---|
| **裸库直读** | **多数宿主** —— 直接告诉它库在哪就行 | 0 |
| 接线注入 | 宿主有生命周期钩子（`SessionStart` 类），想免掉每次手动递 | 小 |
| 其他原生配置 | 宿主有自己的插件机制（`plugin.json` 类） | 按宿主 |

> **先试裸库直读** —— 多数宿主不必写壳。

## 判据

- 验收命令：`python install/verify.py --root <库根>`
- 自检：`python tests/gates_selftest.py --quiet`
- **禁**：在本目录之外的任何地方写宿主真名（`MANIFEST §⑤-2` 禁区的例外仅限 `adapters/**`，但**别依赖例外**）
