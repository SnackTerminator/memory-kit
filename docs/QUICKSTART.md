# 快速上手（QUICKSTART）

> **目标**：**5 分钟内**从零跑到"我的助手已经有记忆了"。
> **前提**：你已经在用某个 AI Agent 产品（本文不教装软件）。

---

## ★ 读我之前的两个约定（**全文适用**）

> **① 占位符必须替换成你的实际值，不可原样粘贴。** 本文里的占位符有**两种形态**，都算占位符：
> 　· **尖括号式**：`<仓库地址>`、`<你给的目录>`、`<你的库>` 等 —— **含程序输出里出现的尖括号**，同样要替换；
> 　· **示例值式**：`D:/my-memory`、`memory-kit.zip`、`/path/to/memory-kit` —— 只是**样例**，请换成你自己的真实路径／文件名。（**不写版本号** —— 示例版号会随套件升版而停旧。）
> 　（PowerShell 里 `<` 是保留的重定向符 ⇒ 把尖括号原样粘贴进命令会直接报 `ParserError`。）
>
> **② Windows 上一律直接写绝对路径**（如 `--target D:/my-memory`）—— **bash 用户也照做**。两个坑：
> 　· **PowerShell**：`~` 不展开 ⇒ 会在**当前目录**建出字面 `~` 文件夹；
> 　· **git-bash／MSYS**：`~` 会展开成 POSIX 风格 `/c/Users/...`，而**原生 Windows 程序（如 Python）不做 MSYS 路径转换** ⇒ 被解析到**当前盘符下的字面 `c\` 目录**（例：在 D 盘执行 ⇒ 落到 `D:\c\Users\...`）。

## 第 1 步：取件

> **解包后先看一眼 `接上我.md` 的名字是否正常**（中文名乱码 ⇒ 换 `python -m zipfile -e` 解包，见下方）。

下面是**"你是从哪儿拿到这个套件"的三种来源**，**任选其一**（完全等价）——**不是要你在包内再找一个 zip**：

```bash
git clone <仓库地址> memory-kit                    # ① 从仓库克隆（需联网）
python -m zipfile -e memory-kit.zip .        # ② 从压缩包解压（★ 推荐 · 跨平台 · 零依赖）
tar -xf memory-kit.zip                       # ②′ Windows 10+ 自带（bsdtar）
cp -r /path/to/memory-kit .                        # ③ 直接复制一份已解压的目录
```

> **⛔ Windows 用户请注意（2026-10-01 实机测试发现 · 重要）**：**不要用 git-bash 自带的 `unzip`**。
> 它是 Info-ZIP 6.00（2009），**不识别 zip 的 UTF-8 文件名旗标**，会把包内**中文名落盘成乱码**（如 `01-记忆档案` → `01-ޫ¦Õ+…`）⇒ 接着初始化会报「**N0 必读件 0 / 5**」并生出一棵**乱码目录树**（**包本身没问题**，先自核 md5）。
> **✅ 同机实测可用的三种**（四法对照，产物 `SOUL.md` md5 一致）：**`python -m zipfile -e`** ／ Windows 自带 **`tar -xf`**（bsdtar）／ PowerShell **`Expand-Archive`**。
> **解包正确性判据（一眼可判）**：解压后 `kernel-skeleton/01-记忆档案/` **名字正常可读** ⇒ 对；**出现乱码目录名 ⇒ 换解压器重解**。

> **若你拿到手时已经是解压好的目录**（如 `memory-kit/`）⇒ **本步已自动完成**，直接进第 2 步。
> **平台注**：本文命令示例用 bash 写法；**PowerShell 下 `cp -r` 等价于 `Copy-Item -Recurse`**，其余命令两平台通用（下文同）。

## 第 2 步：初始化你的记忆库

选一个**你自己掌控的目录**（这就是你说的"记忆放在我自己的文件里"）：

> **★ 选哪里最好？—— 你自己的 U 盘／移动盘。** 本套件叫"U 盘式"，就是让**记忆跟着盘走**：换电脑、换 Agent 产品，插上盘就能读回来。
> **⛔ 不要放网盘同步目录** —— 那等于把私人记忆**静默上云**，与本套件目标冲突；同步冲突副本还会干扰判据。
> **只想先在本地试试** ⇒ 放本机目录也完全可行，只是没有"插盘即用"的便利。
> **若你是把整个包丢给 Agent 让它自己装** ⇒ 让它读 `BOOTSTRAP.md`（Agent 面安装协议 · 六步）。

```bash
python install/init_instance.py --target D:/my-memory
```

你会看到（**实际 6 行**；**件数与字节数随平台／版本略有差异，不必逐字对齐**，下例为本机实测样例）——**⚠️ 务必核对第一行的落盘路径就是你想要的目录**：

```
-- 已写入 14 件 / 39603 B -> <你给的目录>
-- N0 必读件：在位 5 / 5
-- 注入面（库已自足）：python tools/digest.py --root <库目录> --via "L2:自定义指令位"
-- 下一步：让你的宿主读库根 AGENTS.md（读序见 MANIFEST.md）
-- 自检：python install/verify.py --root <库目录>
-- 出生时记忆为空是正常的（N0 新生儿态：不崩 / 不装懂 / 主动索要）
```

> **本步只改一处**：把 `--target` 换成**你自己的绝对路径**。**别写 `~`** —— 理由见文首「约定②」：
> PowerShell 下 `~` **不展开**（会在当前目录建出字面 `~` 文件夹）；git-bash 下会被换成 POSIX 路径（落到 `D:\c\Users\...`）。

> **出生时记忆为空，这是正常的** —— 这叫 **N0 新生儿态**（见下）。

## 第 4 步：让你的助手读它（**一次适配**）

告诉你的 AI 助手一句话即可：

> **"请读 `<你的库目录>/AGENTS.md`，按它指向的顺序读取。"**

`AGENTS.md` **只做一件事**：把控制权交给 `MANIFEST.md`，后者写明**读序**与**必读／按需／禁注入**三段。

**验收判据**：让助手**复述它的读序**（应先 SOUL、后 USER）。复述对了 ⇒ 适配完成。

> **此后不再需要适配** —— 剩下的只是"**记忆的成长**"。

**换机／在别人的电脑上（无需任何配置）**：把库根的 **`接上我.md`** 拖进那个 AI 的对话框即可 —— 它会自己认路、读库、报状态（**L0 递进门**）。想免去「每次递一次」，再按 `docs/接入卡.md` 装一条接线。

## 什么是"新生儿态"（N0）？

你的库刚生成时是**空的**，这是**合法出生态**，不是损坏。此时助手应当：

| 行为 | 含义 |
|---|---|
| **不崩** | 缺件不报错退出，缺什么就明说缺什么 |
| **不装懂** | 没有的记忆**不编**，答"我尚无这条记忆" |
| **主动索要** | 列出需要你补的清单 |

**你会看到它主动开口** —— 先自报一句状态，然后请你给它取个名字、再问几个**可一次点选、也可跳过**的选择题；它**不会一上来就要你打一大堆字**。

## ★ 请你先知道这一件事（隐私）

**物理分离防的是"记忆被装进 Agent 应用里"；它防不了"记忆被 Agent 读走"。**

- 记忆以**普通文件**存在**你选定的载体**上 —— 你能看见、能拷走、能备份；
- 但宿主 Agent **会把读到的内容带进它的上下文** ⇒ **可能随该应用的推理服务离开本盘**；
- 本套件因此约定：**陌生宿主默认只读**（写入需你一句确认）；**读画像件也需你一句确认**（**依约**，非技术强制 —— 无执行体，属**约定**）；
- **敏感内容**放 `01-记忆档案/.private/` ⇒ **陌生宿主不出库**。

> **这是显式取舍**：本套件放弃了"任何宿主零改动读全部"，换取"**陌生宿主不能默默读走你的画像**"。

## 日常怎么用？

| 时机 | 你做什么 | 它做什么 |
|---|---|---|
| 每轮收尾 | 说一句「收个尾」 | 把"以后怎么办"的判断写进画像／运维参考 |
| 它犯错时 | 直接指出 | **当场登记一条教训**（带 host 归因） |
| 阶段复盘 | 说「复盘一下」 | 把可复用方法升格成经验条目 |

**记忆四层**（临时／短期／长期／判据）与**四道闸**（入口／容量／寿命／合并）在后台自动运行 —— **你不必懂**，需要时看 `ARCHITECTURE.md`。

## 出问题？

**先跑一次自检**（多数问题自己会说话）：

```bash
python tests/gates_selftest.py --quiet      # 四闸自检
python install/verify.py --root <你的库>
```

期望：前者末行 `==== 结果：全绿 ⇒ 四闸可用（红 0 项）`；后者末行 `==== 结论：✅ 能用`。

仍不通 ⇒ 看 `docs/TROUBLESHOOTING.md`。
