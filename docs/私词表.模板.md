# 私人关键词表（**模板 · 不随包分发**）

> **本件是模板**：出厂为空，**由你填自己的**。
> **⚠️ 为什么不进发行物**：它**本身就是私人内容**（写了真名/代号）—— 留在包外。
> **用法**：填好 ⇒ 存到**包外**（如家目录或私有仓）⇒ 跑出口闸时用文件路径指给它。

---

## 怎么填

把你**不想出现在发行包里**的词逐行列出来：

- **你的真名/称呼/昵称**（本项目示例已刻意留空，别抄走）
- **你的机器名/用户名/机位代号**（如各机盘符前缀、`h_<uuid>`／`m_<uuid>` 的实际值）
- **你的项目专名/公司名/工号**
- **你的同步根名**（网盘文件夹名、账号名）
- **你的助手人格名**

**粒度**：**够具体**（能命中就是你要防的）｜**别太宽**（如「的」「我」会误报满屏）。

## 格式（**必须照此，否则闸判「无法执行」**）

`tests/zero_private_scan.py` 的判据② 要的是：**`## 一、词表` 标题 ＋ 其下围栏代码块**。

```markdown
# 私人关键词表

## 一、词表

```
<在这里逐行列词>
```
```

> ⚠️ **格式不合 ⇒ rc=3「无法执行」**（**不静默通过**，E718）。这不是 bug，是设计：**闸宁可停下也不假绿**。

## 怎么跑

```bash
# 本机自用（词表在包外）
python tests/zero_private_scan.py --root . --whitelist
python tests/zero_private_scan.py --root . --content --keywords <你的词表路径>
```

**两项都绿**才允许分发。

## 增补时机

新增了私人物（改了昵称？新项目名？换机位？）⇒ **回来补一行** —— 漏补的代价＝包泄露。
